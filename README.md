Features
- The application will include the following core features:
- User Profile and Statistics: This allows users to enter and update their height and weight while also automatically calculating their BMI.
- Daily Calorie Limit: This allows users to set their own desired calorie limit that they will follow every day
- Daily Meal Log: This allows you to add, edit, and delete food entries, which includes food names and nutrition facts.
- Daily Calorie Progress: This calculates the total calories consumed for the day and displays them in a progress bar along with the calorie limit
- Calorie Limit Warning: This provides a warning or a notification when the user's calorie intake exceeds their daily limit.

Screen and navigation plan or Initial wireframes for major screens
The application will consist of the following major screens:
1. Introduction Screen
Shows the application title/name
Gives a short introduction for the application
Provides a start button that will move you to the next screen

2. User Account Registration
Allows you to register an account through your name
Allows you to log in to an existing account through a registered name

3. User Profile 
Gets skipped if the user has an existing account but still accessible for updating information
Input or update weight and height
Automatic calculation of BMI

4. Calorie Goal
Set or update daily calorie limit
View the remaining amount of calories for the day

5. Home screen/Dashboard
Displays a calorie progress bar with the current calorie consumption relative to the limit set
Displays the total of each nutrition inputted
Display the user's BMI

6. Meal Log
Add, delete, and update meal information such as calories, nutrition, etc.
Shows the log of inputted meals and allows you to reuse them.
